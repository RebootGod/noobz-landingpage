# Noobz Landing Page

Landing page statis untuk Noobz Streaming.

## Edit Link

Ganti link tombol langsung di `index.html`:

```html
<a class="primary" href="https://stream.noobz.space">Buka Streaming</a>
<a class="secondary" href="https://t.me/noobzchannel">Telegram</a>
```

## Docker

```bash
docker compose up -d --build
```

Site berjalan di port `3009`.
